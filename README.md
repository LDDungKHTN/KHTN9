# Thí nghiệm ảo: Điện trở – Định luật Ohm (KHTN 9, Bài 11)

Phòng thí nghiệm ảo bằng HTML/JS thuần, gồm 2 thí nghiệm:
1. Tìm hiểu tính chất của điện trở (độ sáng bóng đèn khi thay R₁, R₂, R₃).
2. Sự phụ thuộc của cường độ dòng điện vào hiệu điện thế (bảng số liệu và đồ thị I–U).

## Cách dùng
Mở `index.html` bằng trình duyệt (không cần cài đặt).
Có thể bật GitHub Pages (Settings → Pages → Branch: main, thư mục root) để chạy trực tuyến.

Thao tác: kéo dụng cụ lại gần nhau để tự nối, hoặc kéo dây giữa các chấm đầu nối; bấm vào công tắc K để đóng/mở; kéo tay trượt để chỉnh biến trở.
